# Credits

**HQ General** is maintained by Xlucu. Project work includes touch command design, mobile production and group controls, Android display and lifecycle integration, file and map import, illustrated guides, and engine work on frame pacing, shadows and pathfinding.

- **Electronic Arts and the original developers** — [Command & Conquer: Generals – Zero Hour engine](https://github.com/electronicarts/CnC_Generals_Zero_Hour). The source release uses GPLv3 with EA's additional terms. Original PC game data must be supplied by the player.
- **The Generals engine and port communities** — [TheSuperHackers](https://github.com/TheSuperHackers/GeneralsGameCode), [GeneralsX](https://github.com/fbraz3/GeneralsX), and [tarek369's Android port](https://github.com/tarek369/GeneralsZH-Android). The Android rendering work also draws on [DXVK Native](https://github.com/Joshua-Ashton/dxvk-native) and [l3ad3r1 Android renderer integration](https://github.com/l3ad3r1/GeneralsZH-Android) and [d3d8to9](https://github.com/crosire/d3d8to9).
- **Earlier porting and input work** — [Fighter19](https://github.com/Fighter19/CnC_Generals_Zero_Hour), [ammaarreshi](https://github.com/ammaarreshi/Generals-Mac-iOS-iPad) and [wingear](https://github.com/wingear/GeneralsZH-Android-OpenGL-ES).
- **Community game fixes** — [GeneralsGamePatch2](https://github.com/TheSuperHackers/GeneralsGamePatch2). HQ General adapts selected changes for its Android data importer.
- **Localization** — [MYSOREZ's Android port](https://github.com/MYSOREZ/GeneralsZH-Android-Port) for language resources. Font licenses and provenance are included with the application.
- **Runtime libraries** include SDL, SDL_image, FreeType, OpenAL Soft, GameSpy SDK, GLM and FFmpeg. The startup movie is imported from the player's PC files. ZeroTier One is an independent networking app.
