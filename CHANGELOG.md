# Android release history

## 1.0.1-adaptive.1 · November 24, 2026

First public release under the HQ General name, maintained by Xlucu.

- **Touch and production.** Select units, drag from the command ring, draw movement routes, recall groups, drive a selected Humvee with the joystick and save per-building production presets. The custom editor and illustrated guides explain the gestures.
- **Display and engine.** The Android integration separates the 60 FPS render target from the 30 Hz simulation. Engine work includes reducing repeated shadow and lighting work, avoiding construction-caption allocations for objects that do not display them, and investigating frame stalls from path searches. Device speed depends on the workload.
- **Android multiplayer.** Direct Connect supports phone-to-phone play. The in-game Play online guide explains virtual network setup for players on separate networks.
- **Community changes.** Selected changes from TheSuperHackers' GeneralsGamePatch2 are adapted for Android during import. Credit for the original fixes belongs to their authors.
- **Installation and maps.** Choose the parent folder once to import supported files from your own PC installation. Add skirmish maps or map packs from Android storage. The startup movie is prepared from the supported original file on the phone.
- **Guides and language.** Read the simplified and advanced guides offline or save them as PDFs. The interface and guides support 15 languages.
